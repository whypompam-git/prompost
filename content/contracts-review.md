# ตรวจสัญญา พร้อมโพส — สัญญาลูกค้า & สัญญาจ้างพนักงาน

ตรวจจากโค้ดใน repo (แม่แบบสัญญา `src/lib/contractTemplate.ts`, หน้าสร้าง/ส่ง/เซ็นสัญญา, migration 0030, ข้อมูลพนักงานใน HR) บวกข้อมูลกฎหมายที่ค้นเพิ่ม

> ⚠️ เอกสารนี้เป็นรายการตรวจ/ข้อเสนอ **ไม่ใช่คำปรึกษากฎหมายหรือภาษี** ข้อที่ไม่ได้มีแหล่งอ้างอิงจากการค้นเขียนว่า "(ตรวจกับตัวบท)" —
> ก่อนใช้จริงควรให้ทนายความอ่านแม่แบบรอบสุดท้าย และให้นักบัญชีเช็กเรื่องภาษี/อากรแสตมป์

## 0. สรุปสถานะ

| เอกสาร | สถานะในระบบ |
|---|---|
| สัญญาจ้างทำคอนเทนต์ (ลูกค้า) | **มี** — แม่แบบ 7 ข้อ, ลงนามออนไลน์, เก็บ IP/เวลา/hash, ล็อกแก้ไขหลังเซ็น (trigger ในฐานข้อมูล) |
| สัญญาจ้างพนักงานประจำ | **ไม่มีเลย** (ในระบบมีแค่ชื่อ/ตำแหน่ง/วันเริ่มงาน/เงินเดือน/บัญชีธนาคาร) |
| สัญญา Editor Outsource | **ไม่มี** ทั้งที่ระบบมีตำแหน่ง "Outsource" ที่เห็นฟุตเทจลูกค้า |
| สัญญา MC / นักแสดง | **ไม่มี** ทั้งที่มีหน้า MC และชุดเสนอลูกค้าที่แชร์ข้อมูลบุคคล |
| หนังสือยินยอม PDPA (พนักงาน / MC / คนในคลิป) | **ไม่มี** |

## 1. สัญญาลูกค้า

### 1A. จุดบกพร่องใน "ระบบ" (แก้ได้ในโค้ด)

| # | ปัญหา | ที่มา | ข้อเสนอ |
|---|---|---|---|
| S1 | **ส่งสัญญาให้เซ็นได้ทั้งที่ยังมี `[ระบุ…]` ค้าง** (แค่เด้งถามยืนยัน) — เสี่ยงลูกค้าเซ็นสัญญาที่ไม่ระบุจำนวนคลิป/จำนวนครั้งแก้ฟรี/ค่าปรับเลื่อนคิว แล้วเถียงกันทีหลัง | `contracts/[id]/page.tsx` → `handleSend` | **บล็อกการส่ง** จนกว่าจะกรอกครบ |
| S2 | **จำนวนคลิป/คิวต้องพิมพ์เอง** ทั้งที่แพ็กเกจมี `clip_count` | แม่แบบ ข้อ 1 + ตาราง `packages` | เติมจากแพ็กเกจอัตโนมัติ (ตัวแปร `{{clip_count}}`) |
| S3 | **ไม่มี VAT / หัก ณ ที่จ่ายในสัญญา** ทั้งที่ใบเสนอราคา/ใบแจ้งหนี้ในระบบคำนวณแล้ว — ยอดในสัญญา ≠ ยอดที่ลูกค้าจ่ายจริง | ตาราง `contracts` มีแค่ `total_amount` | เพิ่ม `vat_percent`, `wht_percent` และข้อความ "ราคา (ไม่)รวม VAT / ลูกค้าหัก ณ ที่จ่าย…" |
| S4 | **ผู้ลงนามไม่มีตำแหน่ง/อำนาจ** — ถ้าลูกค้าเป็นบริษัท ใครเซ็นก็ได้ (พิมพ์ชื่อ + วาดลายเซ็น) | `ContractParty` = name/address/taxId/phone | เพิ่มช่อง "ผู้มีอำนาจลงนาม + ตำแหน่ง", อีเมล/LINE สำหรับแจ้งเตือน |
| S5 | **ไม่ยืนยันตัวผู้เซ็น** — ลิงก์เดียวก็เซ็นได้ (ลิงก์หลุด = ใครเซ็นก็ได้) | `api/public/contract-sign` | ยืนยัน OTP ทาง SMS/อีเมลก่อนเซ็น (ช่วยพิสูจน์ตัวตนตาม พ.ร.บ.ธุรกรรมฯ) |
| S6 | **รูปลายเซ็นอยู่ใน bucket สาธารณะ** `client-brand` (`getPublicUrl`) — ใครมี URL ก็เปิดดูได้ | route เดียวกัน + migration 0022 (`public = true`) | ย้ายไป bucket private + signed URL |
| S7 | **IP ที่เก็บมาจาก `x-forwarded-for` ตัวแรก** — ปลอมได้ถ้าไม่ผ่านโปรกซีที่เชื่อถือ | route เดียวกัน | ยืนยันว่าโฮสต์ตั้งค่า header นี้เอง (Vercel ทำให้) และบันทึกเป็นหลักฐานประกอบ ไม่ใช่หลักฐานเดียว |
| S8 | **ไม่ส่งสำเนาฉบับที่เซ็นแล้วให้ลูกค้า** (มีแต่ปุ่ม PDF ฝั่งพนักงาน) | `ContractToolbar` | หลังเซ็น แสดงลิงก์ดาวน์โหลด PDF ให้ลูกค้าในหน้าเดิม / ส่งอีเมล |
| S9 | **ฝั่งผู้รับจ้างเซ็นล่วงหน้าด้วยรูปที่อัปโหลด** และวันที่ใต้ลายเซ็น = วันที่ทำสัญญา ไม่ใช่เวลาที่ผู้รับจ้างยืนยันจริง | `ContractDocument` | พอรับได้ แต่ควรมีข้อความ "ผู้รับจ้างลงนามล่วงหน้า…" หรือบันทึกเวลายืนยัน |
| S10 | **ไม่มีวงจรหลังเซ็น**: ต่ออายุ/สิ้นสุด/ภาคผนวก (เพิ่มคลิป เพิ่มคิว) — แก้ไม่ได้หลังเซ็นโดยดีไซน์ | trigger ล็อกแถว | ทำ "ภาคผนวก/สัญญาต่ออายุ" ผูกกับสัญญาเดิม + แจ้งเตือนก่อนหมดอายุ |

ข้อดีที่มีอยู่แล้ว (เก็บไว้): hash SHA-256 ของข้อความที่ตกลง, เก็บเวลา/IP/User-Agent, ล็อกแก้ไขหลังเซ็นด้วย trigger, ลิงก์ถูกยกเลิกได้, เซ็นซ้ำซ้อนไม่ได้ (`eq("status","sent")`).

### 1B. ช่องว่างด้านเนื้อหาของแม่แบบ

ระดับ: 🔴 ควรมีก่อนใช้กับลูกค้ารายถัดไป · 🟠 ควรมี · 🟡 ดีถ้ามี

**ลิขสิทธิ์ / ผลงาน**
- 🔴 **ไม่ได้ระบุว่าใครเป็นเจ้าของลิขสิทธิ์** ข้อ 5 พูดแค่ "สิทธิ์ใช้งาน" ของผู้ว่าจ้าง — ผลค้นหา (Legardy) ระบุว่า งานที่ว่าจ้างทำโดยเฉพาะ กฎหมายให้ **ผู้ว่าจ้างเป็นเจ้าของลิขสิทธิ์โดยปริยาย เว้นแต่ตกลงเป็นอย่างอื่น** (และเลขมาตราคือ **ม.10 ไม่ใช่ ม.9**) — ถ้าเอเจนซี่ตั้งใจเก็บลิขสิทธิ์/ให้ใช้แบบอนุญาต ต้องเขียนชัด ถ้าตั้งใจโอนให้ลูกค้า ก็ควรเขียน "โอนเมื่อชำระครบ" เพื่อกันลูกค้าเอางานไปใช้ก่อนจ่ายเงิน
- 🔴 **ใช้งานได้เมื่อไรบ้าง**: แม่แบบให้ใช้ "ตลอดระยะเวลาที่ต้องการ" ทันทีที่ส่งมอบ — ควรผูกเงื่อนไข "เมื่อชำระครบทุกงวด"
- 🟠 **ไฟล์ดิบ/ไฟล์โปรเจกต์/ฟุตเทจที่ไม่ได้ใช้**: ใครเป็นเจ้าของ ส่งมอบไหม เก็บรักษากี่เดือนแล้วลบ (ระบบมีลิงก์ Drive ของฟุตเทจ จึงควรกำหนดอายุการเก็บ)
- 🟠 **เนื้อหาที่สร้างด้วย AI**: ถ้าใช้ AI ช่วยผลิต (ภาพ/เสียง/คลิป) ควรมีข้อความเปิดเผย และระบุว่าไม่รับประกันว่าจะได้รับความคุ้มครองลิขสิทธิ์เต็มที่
- 🟠 **Portfolio (ข้อ 5.2)**: ควรมีข้อยกเว้นเมื่อผู้ว่าจ้างแจ้งว่าเป็นความลับ / มีบุคคลในคลิปที่ไม่ยินยอม
- 🟠 **วัตถุดิบจากลูกค้า**: ลูกค้ารับรองว่าโลโก้ รูป สูตร ชื่อสินค้า เพลง ที่ส่งมา เป็นของตนหรือมีสิทธิ์ใช้ และรับผิดชอบหากถูกฟ้อง

**ข้อมูลส่วนบุคคล / ภาพบุคคล**
- 🔴 **ไม่มีข้อกำหนดเรื่องคนที่ปรากฏในคลิป** (พนักงาน/ลูกค้าร้าน/ผู้ป่วย/MC) — ภาพที่ระบุตัวบุคคลได้เป็นข้อมูลส่วนบุคคลตาม PDPA ต้องมีฐานทางกฎหมาย (ปกติคือความยินยอม) ควรกำหนดว่า **ลูกค้าเป็นผู้ขอความยินยอมจากคนของตน** หรือเอเจนซี่เป็นคนขอ (ใช้แบบฟอร์มแนบสัญญา) และใครเป็น "ผู้ควบคุมข้อมูล"
- 🟠 **เงื่อนไขธุรกิจที่มีกฎโฆษณาเฉพาะ** (ลูกค้าคลินิก/สถานพยาบาล/อาหารเสริม/เครื่องสำอาง): ลูกค้าต้องเป็นผู้ตรวจสอบความถูกต้องและการอนุญาตโฆษณา เอเจนซี่ไม่รับผิดต่อคำกล่าวอ้างที่ลูกค้าอนุมัติ (ในระบบมีลูกค้าคลินิกฟันตัวอย่าง จึงเป็นกรณีจริง)

**ค่าบริการ / ภาษี**
- 🔴 **VAT และหัก ณ ที่จ่าย**: ระบุว่าราคารวม/ไม่รวม VAT, ลูกค้านิติบุคคลหักภาษีเท่าไรและต้องส่ง **หนังสือรับรองการหัก ณ ที่จ่าย (50 ทวิ)** ภายในกี่วัน — ผลค้นหา (กรมสรรพากร/กรุงศรี): ค่าโฆษณา **2%**, ค่าจ้างทำของ/บริการทั่วไป **3%** (มาตรา 3 เตรส) ว่างานผลิตคลิปของคุณเข้ากลุ่มไหนให้นักบัญชียืนยัน
- 🟠 **กำหนดชำระ**: "ภายใน X วันนับจากใบแจ้งหนี้" + **ดอกเบี้ย/ค่าปรับชำระล่าช้า** (ตรวจกับตัวบท: ป.พ.พ. ม.224 ดอกเบี้ยผิดนัดตามกฎหมาย 7.5%/ปี ถ้าไม่ตกลงเอง; เบี้ยปรับที่สูงเกินไปศาลลดได้ ตาม ม.383)
- 🟠 **ค่าเดินทาง/ค่าใช้จ่ายนอกแพ็กเกจ**: ข้อ 3 พูดถึง "นอกพื้นที่" แต่ไม่มีเรทหรือวิธีอนุมัติ; **ชั่วโมงถ่ายต่อคิว / OT / จำนวนสถานที่ / จำนวนทีม** ก็ไม่ได้ระบุ
- 🟠 **มัดจำคืนไหม**: ข้อ 6.1 ให้ริบมัดจำงวดแรก **และ** จ่ายค่างานที่ทำไปแล้ว — คลุมเครือว่าหักลบกันไหม ซึ่งเสี่ยงถูกมองว่า "เอาเปรียบเกินสมควร" (พ.ร.บ.ข้อสัญญาที่ไม่เป็นธรรม ใช้กับสัญญาสำเร็จรูปที่ฝ่ายหนึ่งได้เปรียบเกินสมควร ศาลลดผลบังคับได้) ควรเขียนว่า "นำมัดจำไปหักค่างานที่ทำแล้ว ส่วนเกินไม่คืน/คืนตามอัตรา…"

**การทำงาน / ตรวจรับ**
- 🔴 **ช่องทางทางการ**: กำหนดว่า **การกด "ใช้ / ผ่าน / แก้" ในลิงก์ลูกค้า (พอร์ทัล) = การอนุมัติที่ผูกพัน** (ระบบเตือน "ยืนยันแล้วย้อนกลับไม่ได้" และเก็บประวัติรอบแก้ไว้แล้ว) และให้ถือว่าการส่งงานทางพอร์ทัล/LINE ที่ระบุ = ส่งมอบแล้ว — ตอนนี้ข้อ 4.1 พูดถึง "ได้รับงาน" โดยไม่ระบุว่ารับทางไหน
- 🟠 **นิยาม "แก้ไข 1 ครั้ง"**: ระบบนับ "รอบที่ N" ตามบรีฟที่ส่ง แต่สัญญาไม่ได้นิยาม (รวมบรีฟหลายข้อในครั้งเดียวไหม? แก้ซับ/เสียง/โครงสร้าง ต่างกันอย่างไร?)
- 🟠 **ลูกค้าต้องให้ความร่วมมือ**: ส่งวัตถุดิบ/อนุมัติสคริปต์/จัดสถานที่/ผู้ประสานงานภายในกี่วัน ถ้าล่าช้า **กำหนดส่งเลื่อนตามจริง** และเอเจนซี่ไม่ต้องรับผิดชอบ (ตอนนี้มีแต่ภาระฝั่งผู้ว่าจ้างเรื่องการตรวจรับ)
- 🟠 **ความปลอดภัยสถานที่ถ่าย**: ลูกค้ารับผิดชอบอนุญาตให้เข้าพื้นที่และความปลอดภัยของสถานที่ของตน
- 🟡 **ไม่รับประกันผลลัพธ์** (ยอดวิว/ยอดขาย/อัลกอริทึมของแพลตฟอร์ม/การถูกลบหรือจำกัดการเข้าถึง) — เอเจนซี่ควรเขียนเสมอ
- 🟡 **ให้ใช้ Outsource/ผู้รับเหมาช่วงได้** โดยเอเจนซี่ยังรับผิดชอบ และผู้รับเหมาช่วงผูกพันความลับ (ระบบมี Editor Outsource อยู่แล้ว)

**ข้อกำหนดทั่วไปที่หายไปทั้งหมด** (🟠)
- ความลับ (ทั้งสองฝั่ง) และการคืน/ลบข้อมูลเมื่อสัญญาสิ้นสุด
- **ข้อจำกัดความรับผิด** (เพดานความรับผิด = ค่าบริการที่รับจริง ยกเว้นจงใจ/ประมาทเลินเล่ออย่างร้ายแรง)
- **เหตุสุดวิสัย** (ฝนฟ้า, ป่วย, ภัยพิบัติ, แพลตฟอร์มล่ม)
- **การเลิกสัญญา**: ข้อ 6 มีเฉพาะลูกค้าเลิก — ไม่มีกรณีเอเจนซี่เลิก/ผิดสัญญาทั้งสองฝั่ง/ระยะเวลาบอกกล่าวและให้โอกาสแก้ไข
- **กฎหมายที่ใช้และศาล/อนุญาโตตุลาการ** (แม่แบบพูดถึงชลบุรีเฉพาะพื้นที่ถ่ายทำ)
- **ทั้งฉบับ/แก้ไขเป็นหนังสือ/แยกส่วนที่ใช้ไม่ได้/โอนสิทธิ/วิธีส่งหนังสือแจ้ง**
- **การต่ออายุ**

**ผลทางกฎหมายของการลงนามออนไลน์ (ข้อ 7)**
- ข้อความ "มีผลผูกพันตามกฎหมายทุกประการ" ไม่ได้ทำให้เป็นจริงโดยอัตโนมัติ — ผลค้นหา (พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์ ม.7, ม.9): ห้ามปฏิเสธผลทางกฎหมายเพียงเพราะเป็นข้อมูลอิเล็กทรอนิกส์ และลายมือชื่ออิเล็กทรอนิกส์ต้อง **ระบุตัวเจ้าของลายมือชื่อได้ + แสดงว่ายอมรับข้อความ + ใช้วิธีที่เชื่อถือได้** — ระบบเก็บ IP/เวลา/hash ไว้แล้ว แต่ข้อ S4/S5 ด้านบนช่วยเสริมเรื่อง "ระบุตัวได้" มาก
- ผลค้นหาข่าวเดือน ก.ย. 2569 ระบุว่ามี **ร่าง พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์ฉบับใหม่** (ยกระดับลายมือชื่อ/ยืนยันตัวตน) — ติดตามสถานะ

**อากรแสตมป์**
- ผลค้นหา (กรมสรรพากร): สัญญาที่มุ่งผลสำเร็จของงาน = **สัญญาจ้างทำของ ต้องปิดอากรแสตมป์ ลักษณะ 4** — แม่แบบและระบบไม่พูดถึงเลย **ไม่ได้ยืนยันอัตราจากการค้น** ให้ถามนักบัญชี/ดูบัญชีอัตราอากรที่ rd.go.th (ตรวจกับตัวบท: ไม่ปิดอากรทำให้สัญญาไม่เป็นโมฆะ แต่ใช้เป็นพยานหลักฐานในศาลไม่ได้จนกว่าจะชำระอากรและเงินเพิ่ม)
- ข้อเสนอ: ใส่ช่อง "ชำระอากรแสตมป์แล้ว (วันที่/เลขที่)" ในหน้าสัญญา และตัวเตือนหลังลงนาม

## 2. สัญญาฝั่งคน (พนักงาน / Outsource / MC) — ยังไม่มีในระบบ

ก่อนร่าง ต้องจัดประเภทให้ถูก เพราะเอกสารและภาษีต่างกัน:

| ประเภท | ในระบบคือ | สัญญา | ภาษี/ประกันสังคม |
|---|---|---|---|
| พนักงานประจำ / ทดลองงาน | staff ที่มีเงินเดือน (HR → payroll) | **จ้างแรงงาน** (พ.ร.บ.คุ้มครองแรงงาน) | หัก ณ ที่จ่ายเงินเดือน (ภ.ง.ด.1), **ประกันสังคม** — ไม่ต้องติดอากรแสตมป์ (ตามผลค้นหา) |
| Editor Outsource / ช่างภาพฟรีแลนซ์ | ตำแหน่ง `own_only` ("งานของฉัน") | **จ้างทำของ** (วัดที่ผลสำเร็จของงาน ไม่ใช่เวลา/การบังคับบัญชา) | หัก 3% (ภ.ง.ด.3 บุคคล / 53 นิติบุคคล), อากรแสตมป์ลักษณะ 4 |
| MC / นักแสดง / พรีเซนเตอร์ | หน้า MC (ชุดเสนอลูกค้า) | สัญญาใช้ภาพ+ค่าตัว (จ้างทำของ/ให้สิทธิ) | หัก ณ ที่จ่ายตามประเภทเงินได้ |

ข้อควรระวัง: ถ้าปฏิบัติต่อ Outsource เหมือนพนักงาน (กำหนดวัน-เวลา คุมวิธีทำ ทำงานให้เจ้าเดียว) อาจถูกตีความเป็น **สัญญาจ้างแรงงาน** แม้ชื่อสัญญาจะเป็นจ้างทำของ — ระบบมีวัน "ส่งงานภายใน" ซึ่งโอเคในฐานะกำหนดส่งผลงาน แต่อย่าคุมเวลาทำงาน

### 2A. เช็กลิสต์ สัญญาจ้างพนักงานประจำ

หลักการจากผลค้นหา: สัญญาจ้างแรงงานจะทำด้วยวาจาก็ได้ แต่ **ทำเป็นหนังสือเพื่อพิสูจน์เงื่อนไข**; ทดลองงานไม่เกิน **119 วัน** เลิกจ้างได้โดยไม่ต้องจ่ายค่าชดเชย (ถ้าเลยจะเข้าเงื่อนไขชดเชย)

(รายการข้างล่างส่วนที่ไม่มีแหล่งอ้างอิงมาจากความรู้ทั่วไปเรื่อง พ.ร.บ.คุ้มครองแรงงาน พ.ศ.2541 และ ป.พ.พ. บรรพ 3 — **ตรวจกับตัวบท**)

**ข้อมูลพื้นฐาน** — คู่สัญญา/ตำแหน่ง/หน้าที่/ผู้บังคับบัญชา · วันเริ่มงาน · สถานที่ทำงาน (+ออกกองนอกสถานที่/ค้างคืน) · ทดลองงาน (ไม่เกิน 119 วัน) เกณฑ์ประเมิน
**ค่าตอบแทน** — เงินเดือน/วันจ่าย/ช่องทาง (โอนบัญชี) · ค่าล่วงเวลา (อัตราตามกฎหมาย) และ **ค่าออกกองวันหยุด/ค่าเดินทาง/ค่าที่พัก** · โบนัส/คอมมิชชัน (เงื่อนไขชัด) · **การหักเงินเดือน** (ทำได้เฉพาะกรณีที่กฎหมายอนุญาต/ยินยอมเป็นหนังสือ — ข้อความ "ชดใช้อุปกรณ์เสียหาย" ต้องเขียนระวัง) · ภาษี · ประกันสังคม (ขึ้นทะเบียนผู้ประกันตนภายในกำหนดหลังเริ่มงาน) · กองทุนสำรองเลี้ยงชีพ (ถ้ามี)
**เวลาทำงานและการลา** — ชั่วโมงทำงานปกติ · พักระหว่างวัน · วันหยุดประจำสัปดาห์/ประเพณี · ลาป่วย/ลากิจ/พักร้อน/ลาคลอด/อื่นตามกฎหมาย (**ระบบ HR มีแค่ลากิจ/ลาป่วย/ลาพักร้อน** — สัญญาและระบบต้องให้ตรงกัน) · ใบรับรองแพทย์ · เวรกอง/ถ่ายนอกเวลา
**ผลงานและทรัพย์สินทางปัญญา** 🔴 — ผลค้นหา: งานที่ลูกจ้างสร้างระหว่างจ้าง **ตามกฎหมาย (ม.9) ลิขสิทธิ์เป็นของผู้สร้างสรรค์ นายจ้างมีสิทธิ์นำออกเผยแพร่ตามวัตถุประสงค์การจ้างเท่านั้น เว้นแต่ตกลงเป็นหนังสือเป็นอย่างอื่น** → **ต้องมีข้อ "งานทั้งหมดที่ทำในหน้าที่โอนเป็นของบริษัท"** (คลิป สคริปต์ ภาพ ไฟล์โปรเจกต์ แม่แบบ พรอมต์/งานที่ใช้ AI) ไม่งั้นเอเจนซี่อาจไม่มีสิทธิ์โอนต่อให้ลูกค้าได้ตามสัญญาลูกค้า · สิทธิ์ใช้ผลงานเป็น Portfolio ส่วนตัวของพนักงาน (ถ้าจะให้) · เนื้อหาที่ใช้ซอฟต์แวร์/เพลง/ฟอนต์ **ต้องมีลิขสิทธิ์ถูกต้อง**
**ความลับ** — ข้อมูลลูกค้า (แบรนด์บรีฟ ราคา สัญญา รหัสบัญชีโซเชียลของลูกค้า) · ฟุตเทจที่ยังไม่เผยแพร่ · ข้อมูลพนักงานด้วยกัน · **ผูกพันต่อเนื่องหลังออกจากงาน** · ห้ามนำข้อมูล/ไฟล์ออกนอกระบบ
**การห้ามทำงานแข่ง / ชักชวน** — ห้ามรับงานส่วนตัวจากลูกค้าของบริษัทระหว่างจ้าง และชักชวนลูกค้า/พนักงานหลังออก (กำหนดระยะเวลา/ขอบเขตแต่พอสมควร — ข้อห้ามที่กว้างเกินไปศาลอาจไม่บังคับให้ตามความเหมาะสม; อย่าเขียนห้ามประกอบอาชีพทั่วไป)
**ทรัพย์สินและความปลอดภัย** — อุปกรณ์กล้อง/เลนส์/โน้ตบุ๊ก/ไดรฟ์ (ใครเป็นเจ้าของ ดูแลอย่างไร คืนเมื่อออก) · อุปกรณ์ส่วนตัวที่ใช้ทำงาน · ประกัน/อุบัติเหตุออกกอง · โดรน/ยานพาหนะ (ถ้ามี) · บัญชีผู้ใช้ **พร้อมโพส**: PIN เป็นของตน ห้ามให้ผู้อื่นใช้
**โซเชียลและภาพลักษณ์** — การโพสเกี่ยวกับลูกค้า/งานก่อนเผยแพร่ · การใช้ช่องทางของบริษัท · ผลประโยชน์ทับซ้อน/รับของตอบแทนจากลูกค้า
**วินัยและการเลิกจ้าง** — ข้อบังคับการทำงาน (กฎหมายบังคับให้มีเมื่อมีลูกจ้างตั้งแต่ 10 คนขึ้นไป — **ตรวจกับตัวบท** ถ้าน้อยกว่าก็ควรมี) · เหตุเลิกจ้างโดยไม่ต้องจ่ายชดเชย (ตามกฎหมาย) · ระยะเวลาบอกกล่าวลาออก · **การส่งมอบงาน/ไฟล์/รหัสผ่าน/อุปกรณ์เมื่อออก** · ค่าชดเชยตามอายุงาน · ใบรับรองการทำงาน
**ข้อมูลส่วนบุคคลของพนักงาน (PDPA)** 🔴 — ระบบเก็บ ชื่อ เบอร์ อีเมล บัญชีธนาคาร รูป วันเริ่มงาน เงินเดือน (และอาจมีสำเนาบัตร/ใบรับรองแพทย์ซึ่งเป็นข้อมูลอ่อนไหว): ต้องมี **ประกาศความเป็นส่วนตัวสำหรับพนักงาน** (เก็บอะไร ทำไม เก็บนานเท่าไร ใครเข้าถึง ส่งต่อใคร — ประกันสังคม/สรรพากร/ธนาคาร) และความยินยอมเฉพาะส่วนที่ไม่ใช่เพื่อปฏิบัติตามสัญญา/กฎหมาย (เช่น ใช้รูป/ผลงานพนักงานโปรโมตบริษัท)
**ทั่วไป** — กฎหมายที่ใช้/ศาลแรงงาน · ทั้งฉบับ · แก้ไขเป็นหนังสือ · ภาคผนวกคำบรรยายลักษณะงาน

### 2B. เช็กลิสต์ สัญญา Editor Outsource / ฟรีแลนซ์

- ขอบเขตงาน **ต่อชิ้น/ต่อคลิป** (ความยาว สไตล์ ตัวอย่างอ้างอิง ซับ/เพลง/กราฟิกที่รวม) + **ค่าจ้างต่อชิ้น/รอบจ่ายเงิน** (ระบบมีวันส่งงานภายใน ตัวนับรอบแก้ และสถานะ "ส่งตรวจแล้ว" ผูกกับการจ่ายได้)
- **จำนวนรอบแก้ไขฟรี** และนิยามว่าอะไรนับเป็นรอบ (ผูกกับ `revision_count` ในระบบ) — แก้เพราะผิดบรีฟ = ไม่คิดเพิ่ม, ลูกค้าเปลี่ยนใจ = ตกลงเพิ่ม
- **ส่งช้า/คุณภาพไม่ถึง**: ผลกระทบต่อค่าจ้าง สิทธิ์ที่เอเจนซี่จะให้คนอื่นแก้ต่อ
- **ลิขสิทธิ์โอนให้เอเจนซี่** (หรือผู้ว่าจ้างปลายทาง) เมื่อชำระ + ห้ามนำไปโพสเอง/ลง Portfolio โดยไม่ขออนุญาต (ผลงานมีหน้า/ข้อมูลลูกค้า)
- **ความลับและการจัดการฟุตเทจ**: ใช้เฉพาะงานนี้ · ห้ามส่งต่อ/อัปโหลดที่อื่น · **ลบฟุตเทจและไฟล์โปรเจกต์ภายใน X วันหลังส่งงาน** · ไม่เก็บสำเนา
- **รับรองและชดใช้**: เพลง/ฟอนต์/ฟุตเทจสต็อก/ปลั๊กอินที่ใช้มีสิทธิ์ถูกต้อง — ถ้าลูกค้าถูกฟ้องเพราะผู้รับจ้างใช้ของละเมิด ผู้รับจ้างรับผิด
- **ห้ามจ้างช่วงต่อ** โดยไม่ได้รับอนุญาต
- **ไม่ใช่ความสัมพันธ์นายจ้าง-ลูกจ้าง**: ใช้อุปกรณ์/ซอฟต์แวร์เอง เวลาทำงานอิสระ รับงานอื่นได้ (ยกเว้นผลประโยชน์ทับซ้อนกับลูกค้าเอเจนซี่) — ยังต้องเป็นจริงตามการปฏิบัติ
- **PDPA**: ถ้าฟุตเทจมีคน — ผู้รับจ้างเป็นผู้ประมวลผลข้อมูลตามคำสั่งเอเจนซี่
- **ภาษี**: หัก ณ ที่จ่าย 3% + ออกหนังสือรับรอง, ใบเสร็จ/ใบรับรองการรับเงิน · อากรแสตมป์ (จ้างทำของ)
- **การเลิกสัญญา**: เลิกกลางคัน จ่ายตามส่วนที่ส่งมอบแล้ว · ส่งมอบงานที่ค้าง/ไฟล์ทั้งหมด
- **การเข้าถึงระบบ**: ถอนสิทธิ์ลิงก์ Drive/บัญชีในพร้อมโพสเมื่อจบสัญญา (ระบบมี `is_active` อยู่แล้ว)

### 2C. เช็กลิสต์ MC / นักแสดง

- ขอบเขตงาน (วัน เวลา จำนวนชั่วโมง ชุด/แต่งหน้า ใครจัดให้) · ค่าตัว (ต่อวัน/ต่อคลิป) · ค่าเดินทาง/ที่พัก · ค่าล่วงเวลา
- **สิทธิ์ใช้ภาพ/เสียง/ชื่อ**: ใช้ได้ในสื่อไหน (Social / TV / ป้าย / Ads), **ระยะเวลา**, พื้นที่, ใช้ต่อหลังสัญญาไหม (ค่าตัวเพิ่ม), ห้ามตัดต่อให้เสียหาย/ห้ามนำไปใช้กับสินค้าอื่น
- **เอ็กซ์คลูซีฟ** (ห้ามถ่ายให้คู่แข่งช่วงเวลาหนึ่ง) ถ้ามี · มาตรฐานพฤติกรรม/โพสโซเชียลระหว่างแคมเปญ
- **การยกเลิก/เลื่อนวัน** และค่าปรับ/ค่าชดเชยทั้งสองฝ่าย
- **PDPA**: ระบบมีชุดเสนอลูกค้าที่แชร์โปรไฟล์ MC (รูป อายุ ส่วนสูง น้ำหนัก ผลงาน เรท) ผ่านลิงก์สาธารณะ (ซ่อนชื่อจริง/เบอร์/LINE) และนำเข้าข้อมูลจาก Google Sheet → ต้องมี **ความยินยอมของ MC** ในการเก็บ/ส่งข้อมูลให้ลูกค้า (รวมรูปและเรท) และสิทธิ์ถอนความยินยอม
- **ภาษี**: หัก ณ ที่จ่ายตามประเภทเงินได้ + อากรแสตมป์ถ้าเข้าลักษณะจ้างทำของ (ตรวจกับนักบัญชี)
- **ผู้เยาว์** (ถ้ามี MC/นักแสดงอายุต่ำกว่า 20 หรือต่ำกว่า 18): ต้องมีผู้ปกครองลงนาม และกฎหมายแรงงานเด็กมีข้อจำกัด (ตรวจกับตัวบท)

### 2D. เอกสารประกอบที่ควรมีชุดเดียวใช้ทั้งบริษัท
1. **ประกาศความเป็นส่วนตัว (Privacy Notice)** สำหรับ: พนักงาน · ผู้สมัครงาน · MC · ลูกค้า (ระบบเก็บชื่อ/เบอร์/ภาษี/ที่อยู่/บัญชี)
2. **หนังสือยินยอมใช้ภาพบุคคล** (แบบสั้น 1 หน้า ให้คนในคลิปเซ็นหน้างาน/อิเล็กทรอนิกส์)
3. **NDA** (แยกจากสัญญาหลักได้ ใช้กับผู้สมัคร/ฟรีแลนซ์ที่ต้องเห็นข้อมูลก่อนเซ็นสัญญา)
4. **นโยบายใช้อุปกรณ์/บัญชี/ระบบ** (รวมการใช้ AI กับข้อมูลลูกค้า: ห้ามนำฟุตเทจ/สัญญา/ข้อมูลลูกค้าไปใส่เครื่องมือ AI สาธารณะโดยไม่ได้รับอนุญาต)
5. **ข้อบังคับการทำงาน**
6. **บันทึกกิจกรรมการประมวลผลข้อมูล (RoPA)** แบบง่าย — ใครถือข้อมูลอะไรในพร้อมโพส (ตาราง `staff`, `clients`, `mc_profiles`, `contracts` ฯลฯ) และนานเท่าไร

## 3. ลำดับความสำคัญที่แนะนำ

**ทำก่อน (กันความเสี่ยงสูง)**
1. S1 บล็อกส่งสัญญาที่ยังมี `[ระบุ…]` · เติมข้อ 1 อัตโนมัติจากแพ็กเกจ (S2)
2. เพิ่มในแม่แบบลูกค้า: **เจ้าของลิขสิทธิ์/เงื่อนไขโอน**, **VAT+หัก ณ ที่จ่าย**, **พอร์ทัลเป็นช่องทางทางการ**, **ลูกค้ารับรองวัตถุดิบ + ยินยอมคนในคลิป**, **ข้อจำกัดความรับผิด/เหตุสุดวิสัย/เลิกสัญญา/กฎหมายที่ใช้**
3. ร่าง **สัญญาจ้างพนักงานประจำ + ข้อโอนผลงาน** (เพราะตอนนี้ลิขสิทธิ์งานที่ทีมสร้างอาจไม่ได้เป็นของเอเจนซี่ตามค่าเริ่มต้นของกฎหมาย) และ **สัญญา Outsource**
4. Privacy Notice พนักงาน + ความยินยอม MC

**ตามมา**
5. S4–S8 (ผู้ลงนาม, OTP, bucket private, สำเนา PDF ให้ลูกค้า)
6. สัญญา MC/แบบฟอร์มยินยอมภาพบุคคล, NDA
7. ช่องอากรแสตมป์ + ภาคผนวก/ต่ออายุสัญญา

## 4. ต้องให้คนจริงยืนยัน

| เรื่อง | ถามใคร |
|---|---|
| อัตราอากรแสตมป์ของสัญญาจ้างทำของ (ไม่ได้ยืนยันจากการค้น) และวิธีชำระ (e-Stamp) | นักบัญชี / rd.go.th |
| อัตราหัก ณ ที่จ่าย: งานผลิตคลิปนับเป็น "โฆษณา 2%" หรือ "จ้างทำของ 3%" | นักบัญชี |
| ความถูกต้องของเลขมาตราลิขสิทธิ์ (ผลค้นหาเป็นบทความ/ความเห็น ไม่ใช่ตัวบทราชกิจจาฯ) และผลของการให้ผู้ว่าจ้างเป็นเจ้าของโดยปริยาย | ทนายความ |
| ความบังคับใช้ของข้อห้ามแข่งขัน/ชดใช้อุปกรณ์/ค่าปรับ | ทนายความ |
| สถานะร่าง พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์ฉบับใหม่ | ติดตามข่าว / ทนายความ |
| ข้อบังคับ/สิทธิ์ตาม พ.ร.บ.คุ้มครองแรงงานล่าสุด (วันลา, ชั่วโมง, ค่าชดเชย, ประกันสังคม) | ทนายความ / กระทรวงแรงงาน |
| PDPA: แนวปฏิบัติของ สคส. เรื่องภาพถ่าย/วิดีโอในโฆษณา (ผลค้นหาไม่พบแหล่งทางการ) | ทนายความ / pdpc.or.th |
